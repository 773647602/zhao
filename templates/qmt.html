QMT 配置 -- 使用说明

这个 Tab 是干嘛的

配置并测试"大 QMT 桥接"的连接参数。保存后按这里的传输方式 / 地址 / 端口 去连 QMT 里加载的桥策略；"测试连通"会真实 ping 一次。

字段说明

  • 资金账号 -- 必填；zmq 的端口默认按账号自动推导
  • 账号类型 / 传输方式 -- 与服务端一致 (QMT 端 bigqmt 配置)
  • host / port -- zmq 连服务端；redis 连你的 Redis
  • 允许远程下单/撤单 -- 默认关闭。打开后任何能连上通道的程序都可下单，慎重
  • QMT python 目录 / QMT 路径 -- 仅记录存档，本页暂不生成桥接文件

当前生效的 QMT_PATH / ACCOUNT_ID 来自根目录 .env（系统状态页同源），仅作展示，本页不改它。
